# Estudos em Casa

Exercícios extras, práticas de Programação Orientada a Objetos, manipulação de arquivos e pequenos projetos desenvolvidos fora do horário de aula.

## Estrutura

- **Scripts avulsos:**
  - `caracteres.py`: Manipulação de caracteres/strings.
  - `entendendo_algoritmos_recursividade.py`: Prática de recursividade inspirada no livro *Entendendo Algoritmos*.
  - `list_comprehension.py`: Exemplos de *list comprehensions*.
  - `lista_numeros.py`: Operações com listas numéricas.
- `estudos_classe/`:
  - `carro.py`, `classes.py`, `computador.py`, `import_classe.py`.
  - `exercicios_classes/`: `bichinho.py`, `conta_bancaria.py`, `manipulando_arquivo.py`.
- `exercicios/`:
  - `banco/banco.py`
  - `Cadastro/`: `cadastro.py` e `arquivo.txt`
  - `Produto/produto.py`
  - `Sistema_Cadastro/`: `main.py`, `db.py` e `DB/usuarios.db`
  - `validacao/validacao.py`
- `organizador_arquivos/`:
  - `organizador.py`: Organizador automático de arquivos por extensão com interface Tkinter.
- `tracker_estudos/`:
  - Mini projeto de rastreamento de sessões de estudo com SQLite (`main.py`, `materia.py`, `sessao.py`, `repositorio.py`, `tracker.py`, `testes/teste_repositorio.py`).

## Como executar

Entre na pasta do exercício ou projeto desejado antes de executar:

```bash
cd tracker_estudos
python testes/teste_repositorio.py
```
