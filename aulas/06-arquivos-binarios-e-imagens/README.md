# Aula 06 — Arquivos Binários, Diretórios e Imagens

Leitura e escrita de arquivos binários, criação e listagem de diretórios, manipulação de imagens e exercícios com classes e arquivos.

## Estrutura

- `arquivos_binarios/`: `binario.py`, `dados.bin` e `dados_puros.bin`.
- `diretorios/`: `manipular_diretorio.py` e pasta `diretorio_aula/arquivo_aula.txt`.
- `imagens/`: `manipular_imagem.py` (requer `Pillow` instalado).
- `exercicios/`:
  - `agenda.py`, `agendacontatos.py` e `meus_contatos.txt`: Exercícios de agenda com arquivo texto.
  - `resolucao_professor/`: Projeto de gerenciamento de alunos (`aluno.py`, `gerenciador_de_alunos.py`, `main.py`).

## Como executar

```bash
cd exercicios/resolucao_professor
python main.py
```
