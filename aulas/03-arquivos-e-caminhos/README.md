# Aula 03 — Leitura e Escrita de Arquivos e Caminhos

Exemplos práticos de manipulação de arquivos de texto em Python (`open`, `with`, `read`, `readline`, `readlines`, `writelines`), uso do módulo `os` e exercícios de fixação.

## Estrutura

- `manipulando_arquivo/`: Abertura e leitura básica com `exemplo1.py` e `dados.txt`.
- `lendo_arquivo/`: Exemplo adicional de leitura com `exemplo2.py`.
- `readline/`: Leitura linha a linha com `readline_lista.py`, `readlines.py` e `dados.txt`.
- `with_open/`: Gerenciamento de contexto com `with.py`, `with_enconding.py`, `dados.txt` e `exemplo_writelines.txt`.
  > **Nota:** `with.py` contém uma aspa não fechada na string de caminho da linha 17 (preservado conforme o repositório original).
- `os/`: Manipulação de caminhos e arquivos com `os.py` e `dados.txt`.
- `exercicios/`:
  - `agenda_contatos.py`: Controle de contatos em memória.
  - `dicionario_sinonimos.py`: Exercício com dicionário de sinônimos.

## Como executar

Execute os scripts a partir da respectiva subpasta para manter os caminhos relativos válidos:

```bash
cd manipulando_arquivo
python exemplo1.py
```
