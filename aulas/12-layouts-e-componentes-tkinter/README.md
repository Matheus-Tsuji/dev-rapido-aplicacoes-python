# Aula 12 — Layouts e Componentes no Tkinter

Exploração de gerenciadores de layout, posicionamento de janelas, ícones, abas, colunas, relógio em tempo real e exercício de tela de cadastro.

## Estrutura

- `janelas/`:
  - `centralizar_tela.py` e `janela_centro.py`: Centralização de janelas na tela.
  - `janela_icon.py`: Configuração de ícone da janela.
- `componentes/`:
  - `abas.py`: Navegação por abas (`ttk.Notebook`).
  - `colunas.py`: Organização em colunas.
  - `relogio.py`: Relógio atualizado dinamicamente.
  - `desafio.py`: Desafio prático de componentes.
- `exercicios/`:
  - `cadastro.py`: Formulário de cadastro com Tkinter.

## Como executar

```bash
python componentes/relogio.py
python exercicios/cadastro.py
```
