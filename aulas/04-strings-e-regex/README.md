# Aula 04 — Strings e Expressões Regulares

Manipulação de strings e validação de dados utilizando expressões regulares (`re`).

## Estrutura

- `manipulando_string/exemplos.py`: Exemplos de métodos e operações com strings.
- `exercicios/formulario.py`: Formulário com validação de campos utilizando regex.

## Como executar

```bash
python manipulando_string/exemplos.py
python exercicios/formulario.py
```
