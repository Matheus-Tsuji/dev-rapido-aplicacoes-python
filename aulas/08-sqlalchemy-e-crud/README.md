# Aula 08 — Banco de Dados com SQLAlchemy e CRUD

Introdução ao ORM **SQLAlchemy** conectado ao SQLite e exercício de operações CRUD.

## Estrutura

- `sqlalchemy/`:
  - `sqlalchemy_example1.py`: Primeiro exemplo de criação de tabelas e inserção com SQLAlchemy.
  - `sqlalchemy_example2.py`: Consultas e manipulação de registros.
  - `banco_dados.db`: Banco SQLite gerado pelos exemplos.
- `exercicios/`:
  - `crud.py`: Exercício de Create, Read, Update e Delete.
  - `banco_dados.db`: Banco SQLite utilizado no exercício.

## Pré-requisitos

```bash
pip install sqlalchemy
```

## Como executar

```bash
cd sqlalchemy
python sqlalchemy_example1.py
```
