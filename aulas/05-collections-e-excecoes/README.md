# Aula 05 — Collections e Tratamento de Exceções

Uso de estruturas avançadas do módulo `collections` e tratamento de erros com `try / except / finally`.

## Estrutura

- `collections/`:
  - `counter.py`: Contagem de elementos com `Counter`.
  - `defaultdict.py`: Dicionários com valor padrão usando `defaultdict`.
  - `deque.py` e `deque_professor.py`: Filas duplas com `deque`.
  - `namedtuple.py` e `namedtuple_professor.py`: Tuplas nomeadas com `namedtuple`.
- `excecoes/`
  - `try_except_finally.py`: Fluxo de tratamento de exceções.
- `exercicios/`
  - `registro_notas.py` e `notas.txt`: Registro e leitura de notas com persistência em arquivo texto.

## Como executar

```bash
python collections/counter.py
python excecoes/try_except_finally.py
```
