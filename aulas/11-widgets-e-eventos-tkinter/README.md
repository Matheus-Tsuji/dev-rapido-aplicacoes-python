# Aula 11 — Widgets, Eventos e Organização com Classes (Tkinter)

Uso de widgets básicos, tratamento de eventos e estruturação de janelas Tkinter utilizando Programação Orientada a Objetos.

## Estrutura

- `widgets/`:
  - `janela.py` e `janela2.py`: Exemplos de widgets e eventos em Tkinter.
- `layouts/`:
  - `janela_classes.py`: Organização da interface gráfica em classes.

## Como executar

```bash
python widgets/janela.py
python layouts/janela_classes.py
```
