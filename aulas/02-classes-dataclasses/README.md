# Aula 02 — Classes, Dataclasses e Gerenciador de Tarefas

Introdução à Programação Orientada a Objetos em Python com classes tradicionais e `@dataclass`.

## Estrutura

- `alunos/`
  - `Aula1.py`: Classe `Aluno` com cálculo de média de notas.
  - `dataclass.py`: Refatoração do exemplo de `Aluno` utilizando `@dataclass`.
- `taskmanager/`
  - `task.py`: Definição da classe `Task` (título, descrição e status).
  - `taskmanager.py`: Classe `TaskManager` para adicionar, concluir e listar tarefas.

## Como executar

```bash
python alunos/Aula1.py
python alunos/dataclass.py
python taskmanager/taskmanager.py
```
