# Aula 10 — Introdução ao Tkinter

Continuação dos conceitos de classes, dataclasses e banco de dados da [Aula 09](../09-classes-e-sqlite/) e introdução à criação de interfaces gráficas com **Tkinter**.

## Estrutura

- `primeira_janela.py`: Cria uma janela básica, define título, dimensões e inicia o loop de eventos (`mainloop`).

## Como executar

> Requer Tkinter instalado e ambiente gráfico disponível.

```bash
python primeira_janela.py
```
